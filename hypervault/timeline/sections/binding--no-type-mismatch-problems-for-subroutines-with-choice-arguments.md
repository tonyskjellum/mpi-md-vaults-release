## Changes along the time axis

### MPI-2.0 → MPI-2.1  (1 changed paragraph)

A ~~high quality~~ ==high-quality== MPI implementation should provide a mechanism to ensure that MPI choice arguments do not cause fatal compile-time or run-time errors due to type mismatch. An MPI implementation may require applications to use the `mpi` module, or require that it be compiled with a particular compiler flag, in order to avoid type mismatch problems.
